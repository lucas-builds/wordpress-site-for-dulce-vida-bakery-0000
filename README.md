How to put it on your WordPress site (about 2 minutes):
1. Download the theme: https://lucasnode.app/wp/00000000-0000-0000-0000-0000000000f9-8a1dc957163d9281
2. In your WordPress dashboard, go to Appearance > Themes > Add New Theme > Upload Theme, choose the .zip file and click Install Now.
3. Click Activate. Your home page and the other pages are created automatically.
4. To edit text, colors or layout, go to Appearance > Editor. Everything uses the standard WordPress editor (no page builder needed).
